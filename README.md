# Simple ML Project

This project is a simple example of machine learning in Python.

## What the project does

- Loads the Iris dataset from the scikit-learn library
- Creates a DataFrame with pandas
- Splits the data into training and test sets
- Trains a k-Nearest Neighbors (KNN) model
- Evaluates the model accuracy
- Makes a prediction for a single example

## Technologies used

- Python
- pandas
- scikit-learn
- NumPy

## How to run

1. Install the dependencies:

```bash
pip install pandas scikit-learn numpy
```

2. Run the project:

```bash
python main.py
```

## Expected result

The program will display:
- the first rows of the dataset
- the model accuracy on the test set
- a prediction for an example iris flower

## Project goal

This project demonstrates a basic machine learning workflow: loading data, preparing features, training a model, and checking quality.
